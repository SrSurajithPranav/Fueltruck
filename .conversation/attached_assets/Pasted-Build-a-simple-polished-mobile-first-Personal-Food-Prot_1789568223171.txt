Build a simple, polished, mobile-first Personal Food, Protein & Expense Tracker for my own daily use.

Core goal

I want to track:

1. What food I consumed each day
2. How much protein I consumed
3. How much I spent on food
4. My monthly food spending
5. My average daily spending
6. Whether I reached my daily protein target

This is a personal single-user app, not a social/product app.

Keep the project extremely simple and reliable.

---

IMPORTANT: TECH REQUIREMENTS

Build the easiest publishable version possible.

- Frontend: React + TypeScript
- Use Vite
- Mobile-first responsive UI
- Make it a PWA so I can add it to my Android home screen
- No authentication
- No user accounts
- No backend
- No API
- No external database
- No OpenAI/API keys
- Store all data in browser localStorage
- App must work offline after first load
- Deployable directly from Replit
- Keep dependencies minimal
- Do NOT over-engineer
- Do NOT create unnecessary folders, abstractions, services, or APIs

The app should feel like a polished personal Android app even though it is a web app.

Therefore:

Do NOT assume prices are permanently fixed.

But whenever I actually purchase something, I should be able to enter the actual price paid.

Example:

₹65 / 200 g

But today I bought another brand for:
₹58 / 200 g

I should be able to enter ₹58 for that purchase without changing my default price.

Likewise:

Milk ₹22 → another day ₹24

Dosa flour ₹58/kg → another brand ₹65/kg

Soya ₹50/200g → another brand ₹44/200g

The daily log should use the actual price entered for that day's purchase, when applicable.
